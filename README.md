# AAA Mobile Road Creator

A free and open-source Blender add-on for creating procedural roads.

## Features

- Procedural road generation
- Adjustable road width
- Adjustable road length
- Supports Blender 4.x
- Fast workflow

## Installation

1. Download the ZIP from the Releases page.
2. Open Blender.
3. Go to Edit → Preferences → Add-ons.
4. Click Install.
5. Select the ZIP file.
6. Enable the add-on.
